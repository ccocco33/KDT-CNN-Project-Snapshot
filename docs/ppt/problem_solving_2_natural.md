# 문제해결과정 2: 자연스러운 모습 허용 (선글라스, 눈웃음)

## 문제해결과정 2 요약본

- 전제: 사진 앱이므로 자연스러운 모습은 기본 조건 (눈 뜨고 웃는 사진) 을 넘어 허용
  - 허용: 선글라스류, 눈웃음, 한쪽 눈 가림, 수염, 살짝 돌린 고개
  - 허용하지 않음: 두 눈 가림, 입 가림
- 문제 인식: 모델이 자연스러운 모습을 조건 미충족으로 판정
  - 선글라스를 눈 감음으로, 렌즈 반사를 웃음으로 판정
  - 웃느라 가늘어진 눈을 눈 감음으로 판정
- 원인 분석: 학습 데이터에 해당 모습이 부족
  - 실제 선글라스 얼굴이 거의 없음
  - 웃는 눈 데이터가 적고, 학습 목표도 앱 기준보다 낮게 설정
- 해결 방안
  - 허용 규칙 정의: 선글라스류는 눈 뜸, 웃는 눈은 눈 뜸
  - 데이터 추가 후 재학습: 실제 선글라스 (COFW), 웃는 눈 (GENKI)
  - smile 입력에서 눈 영역 제외 (렌즈 반사 차단)
- 적용 결과
  - 선글라스: 눈 뜸 판정 71% -> 95%, 반사를 웃음으로 보는 오판 해소
  - 눈웃음: 소폭 개선에 그침
  - 두 눈 가림: eye 가 눈 감음으로 걸러 허용되지 않음
- 한계: 웃는 눈과 감기는 눈은 눈 모양만으로 구분되지 않고 라벨 기준도 모호

## 문제해결과정 2 지표본

### 측정 조건

- 평가 세트: WIDER 가로 640, 보이는 얼굴, 앱과 같은 자르기. 선글라스 얼굴 dev 38명, holdout 38명
- 앱 eye 기준 0.84 (v0.0.3 은 0.8)
- 스크립트, 결과
  - `evaluation/wider/eye_retrain_compare.py`, `docs/model_versions.md` (v0.0.6, v0.0.7), `docs/dev_spec.md` 10절 8번, 17번, 18번
  - 눈 단계 분석: `tmp/cnn_data_check/results/level_blendshape_auc.txt`, `tmp/ppt/eye_levels.py`, `tmp/ppt/eye_level3_grid.py`
  - 웃음 점수 규칙: `tmp/group_photo_eval/smile_eye_rule.py`, `smile_eye_rule.log`

### 전제: 허용 규칙

- 선글라스류 (선글라스, 색이 짙은 고글) 로 눈이 안 보이면 눈 조건 충족. 투명한 안경은 눈을 그대로 판정
- 가림: 입이 안 보이거나 두 눈이 모두 안 보이면 가림. 한쪽 눈 가림, 수염, 선글라스류는 보임
- 웃는 눈 (^^): 눈 뜸으로 학습 (v0.0.7 부터 학습 목표 1)

### 문제 인식: 선글라스를 눈 뜸으로 판정한 비율

| 모델 | dev | holdout |
|---|---|---|
| 베이스라인 blendshape | 91% | - |
| eye v0.0.1 | 58% | - |
| eye v0.0.3 (기준 0.8) | 66% | 71% |

- smile v0.0.5: 안 웃은 선글라스 얼굴을 웃음으로 dev 5/16, holdout 5/18 (렌즈 반사)
- 웃는 눈: 표지 사진 두 명 eye v0.0.6 0.22, 0.48 (기준 0.84 미만, 감음)

### 원인 분석: 데이터 부족과 학습 목표

| 항목 | 수량 |
|---|---|
| eye 학습 데이터 중 실제 선글라스 | 2,607장 중 13장 |
| 웃는 눈 (단계 2) | 126장 |
| 감기는 눈 (단계 3) | 54장 |

- 웃는 눈 학습 목표 0.7 < 앱 기준 0.84: 웃는 눈을 기준 아래로 내도록 학습한 셈
- 합성 선글라스만으로는 실제 렌즈 반사를 따라가지 못함 (합성 렌즈 종류 추가 재학습 3회, 선글라스 개선 2~3명)

### 해결 방안

- 선글라스 (v0.0.6)
  - COFW 선글라스 얼굴 91장 검수 -> 85장 추가 (실제 선글라스 13장 -> 98장)
  - smile 입력을 얼굴 아래쪽 45% 로 (눈 영역, 렌즈 제외)
- 눈웃음 (v0.0.7)
  - GENKI 웃음 사진 중 눈이 가는 300장 검수 -> 293장 추가 (웃는 눈 126장 -> 273장)
  - 웃는 눈 학습 목표 0.7 -> 1

### 적용 결과: 선글라스

| 지표 | 이전 | 이후 |
|---|---|---|
| 선글라스 눈 뜸 판정 dev | 66% (v0.0.3) | 87% (v0.0.6) |
| 선글라스 눈 뜸 판정 holdout | 71% (v0.0.3) | 95% (v0.0.6) |
| eye AUC holdout | 0.933 | 0.931 (유지) |
| 안 웃은 선글라스 얼굴을 웃음으로 holdout | 5/18 (v0.0.5) | 0/18 (v0.0.6) |
| smile AUC holdout | 0.889 | 0.902 (유지) |

### 적용 결과: 눈웃음

| 지표 | v0.0.6 | v0.0.7 |
|---|---|---|
| eye AUC holdout | 0.931 | 0.941 |
| 뜬 눈을 감음으로 holdout | 20.2% | 19.4% |
| 표지 사진 두 명 eye 점수 | 0.22, 0.48 | 0.50, 0.61 (여전히 기준 0.84 미만) |

- 학습 목표만 바꾼 학습, GENKI 만 추가한 학습은 각각 holdout AUC 변화 없음 (0.931). 둘을 합쳐서야 0.941

### 적용 결과: 두 눈 가림

- 가림 CNN 은 두 눈 가림과 선글라스를 잘 구분하지 못함 (두 눈 가림 실제 학습 데이터 3장, 나머지 합성)
- 손으로 두 눈을 가린 얼굴은 eye 가 감음 (0.19) 으로 판정해 걸러냄 (앱 촬영 1건 확인)

### 한계: 웃는 눈과 감기는 눈의 경계

| 지표 (blendshape) | 뜸 vs 감은 눈 | 웃는 눈 vs 감기는 눈 |
|---|---|---|
| eyeBlink (눈 감음) 로 구분 AUC | 0.987 | 0.615 |

- 눈 감음 정도로는 웃는 눈과 감기는 눈이 거의 구분되지 않음
- 감기는 눈 54장 중 웃는 얼굴 (mouthSmile >= 0.5) 19장. 웃으며 눈이 감긴 얼굴은 감은 눈 단계에도 266장 흩어져 있음
- 감기는 눈 단계에 거의 감은 눈, 웃는 눈, 눈 뜬 얼굴이 섞여 있음 (전체 그리드 확인). 라벨 기준부터 모호
- v0.0.7 도 학습 데이터 웃는 눈의 39% 를 감음으로 판정 (학습에 쓴 이미지라 실제보다 좋게 나오는 값)

### 한계: 웃음 점수로 눈 기준을 낮추는 규칙 (시도, 앱 미반영)

- 규칙: smile 점수 >= 0.7 이면 eye 기준 0.84 -> T. eye 입력 (얼굴 위쪽) 에 없는 웃음 단서를 smile 점수로 줌
- smile 점수 0.7 이상이면 실제 웃음 98% (holdout 579명 중 568명)

| holdout | 앱 기준 (0.84) | T 0.6 | T 0.4 |
|---|---|---|---|
| 웃으며 눈 뜬 얼굴을 눈 뜸으로 | 82.8% | 88.0% | 89.3% |
| 뜬 눈을 감음으로 | 19.4% | 15.5% | 14.5% |
| 감은 눈 recall | 54/59 | 53/59 | 52/59 |

- 학습 데이터 기준 (T 0.4): 웃는 눈 눈 뜸 61% -> 88%, 감기는 눈 19% -> 37%, 감은 눈 1% -> 4%
- 놓치는 감은 눈은 대부분 웃으며 눈을 감은 얼굴 (holdout 감은 눈 중 smile 0.7 이상 13명, 그중 실제 웃음 10명)
- 웃으며 감긴 눈을 허용할지 거를지는 허용 기준부터 정해야 하는 문제로 남김
