## 문제해결과정 1: 학습 데이터 전처리와 증강

- 문제 인식 (v0.0.1 을 팀 학습 test 와 단체 사진 평가 세트로 측정. `tmp/v001_test/measure.py`)
  - eye: 학습 test AUC 0.985 -> 단체 사진 0.725. test 에서는 거의 완벽한데 실사용에서 무너짐
  - smile: 학습 test 0.943 -> 단체 사진 0.831. eye 와 같이 test 에서는 괜찮은데 실사용에서 떨어짐 (v0.0.1 smile 은 드라이브 v13)
  - 베이스라인 blendshape: smile 0.933, eye 0.908
- 원인 분석
  - eye: 두 클래스의 출처가 다름 -> 눈 대신 출처의 흔적 (자른 방식, 해상도, 색) 으로 구분할 수 있음
    - 학습 test 의 opened 449장은 모두 161px, closed 358장 중 161px 은 2장 (중앙값 149px). 흑백 opened 2장, closed 22장
    - test 도 같은 출처에서 나눠 흔적이 그대로 통함 -> test 점수로는 문제가 드러나지 않음
    - 단체 사진 60px 미만 얼굴 AUC 0.69~0.72
  - smile: 얼굴 크기와 무관하게 전 구간 0.80~0.86. 학습 데이터 (GENKI, 정면에 가깝고 큰 얼굴) 와 단체 사진의 차이를 증강이 메우지 못함 (회전 약 ±9도, 흐림, 저해상도 없음)
- 해결 방안
  - 전처리: 모든 학습 이미지를 YuNet 으로 다시 잘라 앱과 같은 방식 (박스 높이 정사각형), 64px 로 통일, 흑백 제외 -> 출처의 흔적 제거
  - 증강: 회전 20도, 저해상도 (24~56px), 흐림, 밝기, 대비, 채도 -> 단체 사진의 작고 흐린 얼굴
  - smile 에서 먼저 확인한 방식을 eye 에 한 번에 적용
- 적용 결과 (단체 사진 holdout)
  - smile 학습 단계별: v0.0.1 0.831 -> 전처리 + 증강 0.879 (+0.048) -> EMA, 증류 등 0.889 (합쳐서 +0.010). 증가분의 약 83% 가 첫 단계
    - 학습 test 와 단체 사진의 차이: v0.0.1 -0.112 -> v0.0.2 -0.071 (test 0.960, 단체 사진 0.889)
    - 첫 단계에는 학습 방식 변경 (팀 노트북 -> 새 노트북) 도 섞여 있어 전처리, 증강 각각의 기여는 나누지 못함
  - eye: v0.0.1 0.725 -> v0.0.3 0.933 (베이스라인 0.908 초과). 60px 미만 얼굴 0.69~0.72 -> 0.90~0.94

## 문제해결과정 2: 자연스러운 모습 허용

- 문제 인식
  - 요구사항: 입이 가려진 얼굴은 촬영 전에 거름 (가림 CNN. 가림 recall 63%, 보이는 얼굴 오판 1.7%)
  - 예외: 본인 스타일일 가능성이 높은 모습은 허용 (선글라스, 한쪽 눈 가림, 수염, 살짝 돌린 고개)
  - 그중 선글라스가 어려움: 앱 촬영에서 렌즈에 반사가 비치면 eye 는 감음, smile 은 웃음으로 오판 (200px 이상 50장 중 eye 뜸 0장)
- 원인 분석 (선글라스가 어려운 이유)
  - 모델 세 개가 모두 맞아야 함: 가림 CNN 통과 (0/38 로 문제없음), eye 가 뜸, smile 이 반사에 속지 않음
  - 눈 판정 원칙과 부딪힘: 감은 눈을 놓치지 않으려 기준을 높이면 선글라스가 감음으로 떨어짐 (기준 0.8 로 올렸을 때 선글라스 뜸 38/38 -> 27/38)
  - 실제 데이터가 없음: eye 학습 2,607장 중 실제 선글라스 13장. 합성 반사 증강으로 3회 재학습했으나 선글라스 개선 2~3명
  - 평가 세트에서 잘 안 보임: 반사는 가까이 (약 120px 이상) 찍을수록 심한데 WIDER 선글라스 얼굴 76명은 높이 중앙값 53px, 120px 이상은 4명. 앱 평가 화면 연속 촬영으로 발견
- 해결 방안
  - smile: 입력에서 눈 영역을 뺌 (얼굴 아래쪽 45%. 눈 중심 높이 약 37%, 렌즈 아래 끝 약 52%)
  - eye: 실제 선글라스 데이터 추가 (COFW 에서 검수한 85장)
- 적용 결과 (v0.0.5 -> v0.0.6)
  - eye AUC 0.933 -> 0.931 (유지). 선글라스를 뜸으로 74% -> 95%
  - smile AUC 0.889 -> 0.902 (유지). 안 웃은 선글라스 얼굴을 웃음으로 5/18 -> 0/18
  - 앱 촬영 (증상 확인용): 200px 이상 50장 중 eye 뜸 0 -> 29장, smile 웃음 33 -> 15장
- 한계
  - 선글라스 일부는 여전히 감음: 감은 눈 recall 을 우선한 기준 (0.84) 의 대가. 노트북 기준 0.712 면 선글라스 뜸 100% 지만 감은 눈 recall 93% -> 86% (Threshold 절과 연결)
  - 두 눈 가림: 가림 판정에서 선글라스와 구분이 어려움 (두 눈 가림 실제 데이터 부족). 앱 촬영에서 손으로 두 눈을 가린 얼굴은 eye 가 감음 (0.19) 으로 걸러냄 (1건 확인). 일부러 두 눈만 가리는 경우는 드물다고 보고 그대로 둠
  - smile 은 눈가 단서 없이 입, 볼로만 판정
